数学公式

行内公式

用一对美元符号包围 LaTeX 数学表达式，使公式出现在正文中：

勾股定理：$a^2 + b^2 = c^2$
分数：$\frac{1}{2}$

独立公式块

将两个美元符号分别放在公式前后的独立行：

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

也可以使用标记为 math 的代码块：

```math
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
```
公式由 MathJax 渲染，支持许多常用 LaTeX 数学命令，但不等同于完整的 LaTeX。当前不支持用 \(...\) 或 \[...\] 作为 Markdown 公式分隔符。

常用公式写法

  • 上下标：$x^2$、$a_i$；多个字符用花括号，如 $x^{n+1}$。
  • 分数与根号：$\frac{a}{b}$、$\sqrt{x}$。
  • 希腊字母：$\alpha$、$\beta$、$\pi$。
  • 求和与积分：$\sum_{i=1}^{n} i$、$\int_0^1 f(x)\,dx$。

其他说明

  • 在特殊符号前输入反斜杠，可以显示符号本身，例如 \*。
  • 普通行内代码和代码块中的内容按代码显示，不作为 Markdown 或公式解析；标记为 math 的代码块用于显示公式。
  • 部分原始 HTML 可能被过滤；脚本和不安全的内容不会执行。
